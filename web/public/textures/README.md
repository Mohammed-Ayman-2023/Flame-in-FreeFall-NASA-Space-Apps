# Textures

- `earth-blue-marble-2k.jpg`, `earth-topology-2k.jpg`, `earth-water-2k.jpg`: NASA Blue Marble imagery (NASA Visible
  Earth, public domain), resized to 2048 × 1024 from the copies distributed in the `three-globe` npm package (MIT).
- The Moon and Mars surfaces are generated in the browser (`web/src/components/SpaceScene.jsx`) and are illustrations,
  not maps.
