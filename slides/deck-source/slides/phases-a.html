11 · The approach, phases 1–3

Understand the data, then structure it

Phase 1

Explore NASA PSI

Find the actual datasets, experiment descriptions, papers, and downloadable files.

Identify which investigations have structured numerical data versus only documents and reports.

Phase 2

Build a unified data model

Normalize investigations, experiments, fuels, conditions, sensors, and results.

This gives you a searchable scientific knowledge base.

Phase 3

Implement scientific search

Enable keyword search, metadata filters, and semantic retrieval.

Make sure users can find an experiment even if they don’t know its NASA investigation name.
