07 · AI technology 1 · Probably the most important component

RAG — Retrieval-Augmented Generation

Suppose a user asks: “Which experiments studied flame extinction using CO₂?”

A normal LLM

Might generate an answer based on its training knowledge.

But that is not sufficient for scientific research.

Instead

  1. Search the NASA database.
  2. Retrieve relevant experiments and documents.
  3. Extract relevant passages and measurements.
  4. Give those sources to an LLM.
  5. Ask the LLM to generate an answer based on the retrieved evidence.
  6. Display citations to the original sources.

This is RAG.
